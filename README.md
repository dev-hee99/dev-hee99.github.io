## 🛠️ 설치 및 실행

### 필수 요구사항
- Node.js 16 이상
- npm 또는 yarn

### 설치

```bash
git clone https://github.com/dev-hee99/dev-hee99.github.io.git
cd dev-hee99.github.io
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

### 빌드 및 배포

```bash
npm run build
npm run deploy
```
